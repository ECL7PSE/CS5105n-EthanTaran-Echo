# Echo

## Game Idea
Echo is a 2D dark-fantasy action-platformer set in a mysterious and forgotten world. The game features strange and unique characters, eerie environments, hidden secrets, and a dark but beautiful atmosphere.

The player explores the world, encounters unusual creatures and characters, and faces dangerous enemies while uncovering the mysteries surrounding the world. Death is an important part of the experience, with each attempt bringing the player closer to understanding the world and overcoming its challenges.

## Genre
2D Dark-Fantasy Action-Platformer
